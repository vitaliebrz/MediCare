## Convenții pentru un plan nou
- Fișier: `docs/plans/<modul>.md`, adăugat în tabelul de mai sus.
- Secțiuni: context, structura paginii, decizii de date (cu motivul), fișiere, reguli, „Nu intră în acest modul”.
- La final: starea devine „implementat”, iar abaterile de la plan se notează în document.
